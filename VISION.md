# Wimzo vision

Give a developer a durable way to turn product requirements into reviewed software through conversation.

Requirements live with each project. Work approval, execution, verification and release are separate decisions. Runs have persistent records and can be recovered after interruption. The browser interface is optional: CLI and MCP expose the shared operations.

This is a personal experimental project. The specifications describe direction as well as implemented behavior; see README.md for current scope and limitations.
